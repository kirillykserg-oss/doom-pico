# Doom для Raspberry Pi Pico + екран 128x160 + твої кнопки

Це набір змін до готового порту Doom для RP2040. Прошивка збирається **автоматично на GitHub**
(на твоєму комп'ютері нічого ставити не треба) і на виході дає ОДИН файл `DOOM.uf2`.

> Увага: цей набір я не міг запустити на справжній платі. Зміни зроблено за твоєю розпайкою
> і за кодом автора, але можуть знадобитися дрібні підстройки (орієнтація, кольори, зсув) -- див. розділ 4.

## 1. Підключення (так, як у тебе зараз)

| Екран | Pico |
|---|---|
| VCC | 3V3 |
| GND | GND |
| SCL / SCK | GP18 |
| SDA / MOSI | GP19 |
| CS | GP17 |
| DC / A0 | GP16 |
| RES / RST | GP20 |
| BL / LED | 3V3 |

Кнопки (на GND, внутрішнє підтягування): Up GP2, Down GP3, Left GP4, Right GP5, A GP6, B GP7, START GP8.

## 2. Збірка на GitHub

1. Зайди на github.com, створи акаунт (безкоштовно) і новий репозиторій (кнопка **New**), назви `doom-pico`.
2. Розпакуй цей архів. У репозиторії натисни **Add file → Upload files** і перетягни туди
   **весь вміст** розпакованої папки (папки `overlay` і `.github`, файли `make_uf2.py`, `doom1.whx`, `README_UA.md`).
   Натисни **Commit changes**.
   Якщо папка `.github` не завантажилась: **Add file → Create new file**, у назві введи
   `.github/workflows/build.yml` і встав вміст файлу з архіву.
3. Відкрий вкладку **Actions**. Збірка стартує сама після коміту (або обери "Build Doom for Pico" → **Run workflow**).
   Вона триває кілька хвилин. Зелена галочка означає успіх.
4. Відкрий завершений запуск, унизу в розділі **Artifacts** завантаж `DOOM-uf2`, розпакуй -- там `DOOM.uf2`.
5. Затисни BOOTSEL на Pico, підключи USB, відпусти кнопку і скопіюй `DOOM.uf2` на диск **RPI-RP2**.
   Копіювання 2 МБ займає кілька секунд, Pico сама перезавантажиться і запустить Doom.
   (Це замінює MicroPython. Щоб повернути Маріо, заново прошийте MicroPython і збережіть `main.py`.)

Якщо збірка червона, відкрий її, знайди перший червоний крок, скопіюй текст помилки і надішли мені.

## 3. Керування в грі

- ⬆️⬇️ -- вперед/назад, ⬅️➡️ -- поворот
- 🔵 B -- стріляти
- 🔴 A -- відкривати двері/активувати, утримання разом зі стрілками -- біг
- ⏸️ START -- Enter (вибір у меню) і Tab (карта)
- A + START -- Esc (відкрити/закрити меню) і наступна зброя
- Початок гри: A + START (меню) → New Game

## 4. Підстройка, якщо картинка не така

Усе в файлі `overlay/src/pico/magc.h` (редагуй прямо на GitHub: олівець у правому куті файлу → Commit → збірка запуститься знову):

- **Картинка догори ногами або дзеркальна:** у `DISPLAY_ADDRESS_MODE` для ST7735 заміни `DCS_ADDRESS_MODE_MIRROR_Y` на `DCS_ADDRESS_MODE_MIRROR_X`.
- **Червоний і синій поміняні місцями:** заміни `DCS_ADDRESS_MODE_BGR` на `DCS_ADDRESS_MODE_RGB`.
- **Смуга шуму з краю або зсув картинки:** заміни `DISPLAY_OFFSET_X`/`DISPLAY_OFFSET_Y` на `1` і `2` (або `2` і `1`).
- **Шум, мерехтіння по всьому екрану:** зменш `DISPLAY_SPI_CLOCK_SPEED_HZ` (наприклад до `8000000`).
- Білий екран: перевір піни з розділу 1.

Піни екрана змінюються в `overlay/src/pico/CMakeLists.txt` (блок `LCD_*`), кнопок у `overlay/src/pico/i_input.c` (`PIN_*`).

## 5. Що змінено порівняно з готовою збіркою автора

- Піни екрана: DC GP16, RST GP20, підсвітка від 3V3 (в автора DC GP20, RST GP21, BL GP22).
- Піни кнопок під твою розпайку, прибрано кнопку SELECT (GP28).
- Новий тип екрана `ST7735` (режим 160x128 як у ST7789, ініціалізація з перевіреної MicroPython-версії, SPI 16 МГц).
- Прошивка зібрана як самостійна (без завантажувача `rp2040-retro-loader`) і разом із рівнями складається в один `DOOM.uf2`.

Основа: rp2040-doom (Graham Sanderson) і порт на LCD від dahai (ILI9341/ST7789).
